The protocol

Plan → Execute → Verify

A declarative loop that turns a high-level intent into a proven outcome. No chatty back-and-forth — just a plan you can inspect, atomic execution, and an AI verification of intent.

01

Plan

Send a high-level intent. The runtime returns a structured, inspectable plan with dependency placeholders between actions.

POST /api/documents/{id}/plan
02

Execute

Approve the plan and the server runs every action atomically. Placeholders like $node_0.id resolve at runtime.

POST /api/documents/{id}/execute
03

Verify

The runtime uses AI to confirm the intent was achieved — returning findings, a confidence score, and an audit trail.

POST /api/documents/{id}/verify

Composable actions

One declarative call. Built-in dependencies.

Chain actions that reference each other's outputs. The runtime resolves the dependency graph before a single byte is written.

plan.json
{
"actions": [
{ "node_id": "node_0",
"action": "add_chapter",
"params": { "title": "Market Analysis" },
"depends_on": [] },
{ "node_id": "node_1",
"action": "add_section",
"params": { "title": "Competitors",
"chapter_id": "$node_0.id" },
"depends_on": ["node_0"] },
{ "node_id": "node_2",
"action": "write_page",
"params": { "section_id": "$node_1.id" },
"depends_on": ["node_1"] }
]
}
add_chapterAdd a chapter to the document
add_sectionAdd a section to a chapter
write_pageWrite content to a new page
edit_pageModify an existing page in place
delete_pageRemove a page from the document
Python SDK

Five lines to document intelligence.

Initialize, extract, build. OfficePlane's SDK gives your agent full document capabilities in a few lines of Python. The harness handles orchestration, the skills handle execution.

intentDeclare intent, not steps — the harness figures out the execution graph
verifyBuilt-in verification — every result comes with a confidence score
driversSwap drivers, keep the code — LibreOffice today, Google Docs tomorrow
example.py
from officeplane import OfficePlane
# Initialize with a driver
plane = OfficePlane(driver="libreoffice")
# Extract document structure
doc = await plane.prettify("report.docx")
print(doc.chapters) # 8 chapters, 23 sections
# Build a new document from extracted structure
result = await plane.build(
source=doc,
schema="exec_summary",
rules=["max 2 pages", "include KPIs"]
)
print(result.confidence) # 0.97
print(result.path) # ./output/exec-summary.docx
